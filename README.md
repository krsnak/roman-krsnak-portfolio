# Roman Kršňák — profesní portfolio

Statická jednostránková prezentace pro freelance zakázky: AI automatizace, systémové integrace, API a interní nástroje.

**Live:** https://roman-krsnak-portfolio.pages.dev

## Lokálně
Není potřeba build. Otevřete `index.html`, případně spusťte `python3 -m http.server 8080`.

## Cloudflare Pages
Projekt je čistý statický web. V Cloudflare Pages připojte GitHub repository, Framework preset nastavte na `None`, build command nechte prázdný a output directory nastavte na `/` (root projektu).

## Obsah
Reference jsou formulované jako vlastní/interní projekty, nikoli klientské zakázky. Facebook není uveden záměrně.
